# 环肽展示的生物合成机理模拟

`src/litrapid/biosynthesis.py` — mRNA display / phage display / bacteria display
的分步机理模拟。

## 1. 这一层解决什么问题

平台原有两个模块都把"能不能做出这个分子"当作已知：

| 模块 | 对生物合成的处理 | 缺口 |
|---|---|---|
| `mrna_display.py` | `fusion_probability` = 四个常数相乘，**所有序列取同一个值**；环化按"有无 Cys"二值处理 | 两条亲和力相同但可制造性差一个数量级的序列，得到完全相同的选择权重 |
| `display_loop.py` | yeast / phage 后端用长度窗口、疏水比例、电荷比例做**加和式启发式扣分** | 没有转化上限、没有转运、没有环化动力学、没有扩增偏倚；完全没有细菌展示 |

真实campaign首先回答的不是"哪条序列结合最紧"，而是**"这个平台在物理上能不能把这个分子做出来"**。
本模块按中心法则逐步走完这条路径，并在机理要求的地方把每一步的存活概率写成序列的函数。

## 2. 三类损失必须分开记账

| 类别 | 含义 | 后果 |
|---|---|---|
| `bulk` | 与序列无关的标量效率 | 损失**分子数**（产率），不损失序列空间 |
| `ceiling` | 对**不同变体数**的硬上限（转化、分选通量） | 损失**文库多样性**，与产率无关 |
| `sequence` | 与序列相关的存活概率 | 改变**剩下的是哪些序列** |

第三类是唯一会在任何"用展示输出训练的模型"里变成隐式先验的损失。
Collins 等在 *Cell Systems* 综述中指出的"模型需要纳入细胞类型、宿主及环境等生物学背景"，
在展示技术里首先就体现为这一类损失。

## 3. 多样性的传播方式

分子数与变体数分别传播。某变体有 `n` 份拷贝、单步存活概率为 `p` 时，至少一份存活的概率为

```
P(变体存活) = 1 - exp(-n * p)
```

对抽样得到的序列分布求和得到变体数，对 `n*p` 求和得到分子数。两条曲线之间的间距，
就是"损失了材料"与"损失了文库"的区别 —— 这正是启发式评分无法表达的部分。

## 4. 三条路径的机理步骤

### 4.1 mRNA display（RaPID，无细胞）

`DNA → TXN → LIG → ACYL → TRL → FUS → CYC → RT → PUR`

关键机理：

- **LIG（嘌呤霉素接头连接，0.75）**：这一步*建立*基因型-表型连接，其效率是下游所有步骤的硬乘数。
- **ACYL（柔性酶装载起始 tRNA，0.50）**：用 eFx/dFx 核酶把 ClAc-D-Tyr 装到 tRNA-fMet 上。
  **这是非天然化学的唯一来源，任何基于细胞的平台都没有对应步骤。**
- **TRL（PURE 翻译）**：缺 RF1，因此 NNK 必然引入的琥珀密码子可被重新指派而非终止。
  N-甲基与 D-型残基是较差的 A 位底物，连续 N-甲基的停滞远重于孤立者 ——
  这正是"为渗透性而加 N-甲基"不能无限加码的约束。
- **FUS（嘌呤霉素进入 A 位，0.25）**：全流程最大的 bulk 损失。
- **CYC（自发硫醚环化）**：Cys 硫醇盐对 N 端氯乙酰的分子内 SN2，与水解、分子间烷基化竞争。
  效率按环大小的对数正态有效摩尔浓度建模；第二个 Cys 不阻断成环，但把物料分配到两个环尺寸
  （区域异构体混合物）—— 二值"有无 Cys"判据无法表达这一点。

### 4.2 Phage display（M13 pIII）

`DNA → XFORM → SUP → EXP → FOLD → PROT → ASSY → PROP`

- **XFORM（电转化，上限 10^10）**：**所有基于细胞的平台的多样性天花板**。
  12 位 NNK 设计编码 4×10^15 条序列，因此设计的 99.999% 以上从未被物理合成出来。
- **SUP（supE 琥珀抑制，0.60）**：TAG 被读作 Gln。注意这不是丢失，而是**序列被静默改写**，
  造成 mRNA display 中不存在的系统性 Gln 富集。
- **EXP（Sec/SRP 转运）**：阳性在内规则 —— 成熟区净正电荷对抗质子动力势而阻碍转运；
  强疏水性导致错误靶向内膜或包涵体。
- **FOLD（DsbA 氧化成环）**：这里唯一可遗传编码的环化方式。需要随机区自己提供一对 Cys。
- **PROT（OmpT/DegP）**：OmpT 在连续碱性残基之间切割 —— 这是该平台特有的序列空间空洞。
- **ASSY（单价展示，0.12）**：噬菌粒+辅助噬菌体体系下，携带至少一份融合拷贝的病毒粒子约 10%。
  单价性正是噬菌体淘选由亲和力而非亲和力-亲合力混合驱动的原因，代价记在产率上。

### 4.3 Bacteria display

两条路线分别建模：

**SICLOPPS（胞内首尾环化）** `DNA → XFORM → EXPR → SPLICE → TOX → SORT`

- 外显肽第一位被**固定为 Cys**，因为剪接需要亲核试剂 —— 一个环上位点被化学而非识别占用。
- **SPLICE**：Npu DnaE 剪接对催化 Cys 之后那一位敏感，脯氨酸几乎完全阻断酰基迁移；
  失败路径走 N 端切割，释放线性副产物而非大环。
- **TOX**：无偏环肽文库对表达它的宿主有相当比例的生长抑制，
  这部分损失按电荷与疏水性有偏，且**每一轮都发生**。
- 转化上限 10^9 与分选上限 10^8 共同决定：适配该平台的环尺寸由上限而非化学决定，
  这就是 SICLOPPS 文库普遍建在 5–6 个随机位（32^5 = 3.4×10^7）而不是 12 位的原因。

**eCPX 表面展示** `DNA → XFORM → EXP → FOLD → PROT → TOX → SORT`，
在还原性胞质外，可用二硫环化，但分选通量成为第二个上限。

### 4.4 Yeast display（真核对照）

保留 `yeast_aga2` 以便与 `display_loop.py` 的已有后端对齐，并额外建模
**N-糖基化**：N-X-S/T 序列子被糖基化后，展示出来的已经不是设计的那个化学实体。

## 5. 模拟结果（12 位 NNK，6000 条抽样）

| 平台 | 最终不同大环数 | 总产率 | 产率限制步 | 多样性限制步 |
|---|---|---|---|---|
| mRNA display (RaPID) | 5.0×10^10 | 6.5×10^-3 | FUS | PUR |
| Bacterial SICLOPPS | 1.0×10^8 | 1.9×10^-4 | XFORM | SORT |
| Phage display (M13) | 6.3×10^6 | 9.8×10^-7 | FOLD | PROP |
| Bacterial surface (eCPX) | 2.9×10^6 | 5.9×10^-6 | FOLD | SORT |
| Yeast display (Aga2p) | 2.2×10^4 | 4.0×10^-8 | XFORM | SORT |

三个可直接用于决策的结论：

1. **无细胞路径保留的文库规模高于每一条基于细胞的路径，但倍数随平台差别很大**：
   相对 SICLOPPS 为 495 倍，相对噬菌体 7.9×10^3 倍，相对 eCPX 1.7×10^4 倍，相对酵母 2.2×10^6 倍。
   四条细胞路径的共同点不是倍数，而是**都在转化步被硬上限截断**（`ceiling_applied` 在 XFORM 全部为真），
   而无细胞路径全程没有任何上限步。若课题需要 >10^10 的真实多样性，平台选择在这一步就已决定，
   与打分函数无关；但若 10^8 量级够用，SICLOPPS 与无细胞路径的差距只有约两个半数量级。
2. **随机化 Cys 的 NNK 文库在噬菌体上几乎做不出环肽**：成环效率仅 2.6%。
   把 Cys 固定为 CX7C 支架后，同一条噬菌体路径的成环效率升到 63%，
   最终不同大环数恢复 25 倍（6.3×10^6 → 1.6×10^8）。
   这与真实噬菌体环肽文库普遍采用固定 Cys 支架而非随机化 Cys 的实践一致，可作为该模块的行为验证。
3. **序列先验跟随的是具体的生物合成步骤，而不是"是否在细胞内"**。
   周质/分泌型二硫路径（phage、eCPX、yeast）在接触靶点之前就施加了明显先验：
   Cys 富集 +2.53/+2.51/+2.51 log2（成环化学要求随机区自备一对 Cys），
   Lys/Arg 耗竭 −0.57/−0.55（阳性在内规则 + OmpT 双碱性切割），Ile −0.52（疏水转运惩罚）。
   **胞质内含肽路径（SICLOPPS）并不施加这一先验**：Cys 为 −0.13（而非富集，因为 Cys 由载体固定，
   无从富集）、Ile +0.01、Lys/Arg −0.07/−0.05，全部 20 种残基的 |bias| ≤ 0.22，
   最大偏倚出现在 Glu/Asp（+0.22/+0.21，来自毒性筛除对阳离子序列的清除）——
   该路径既没有 Sec 转运步，也没有 OmpT 步，因此没有产生这些先验的机理来源。
   无细胞路径同样平坦（|bias| ≤ 0.09）。
   结论对建模的含义是：**先验必须按路径的步骤组成来建，不能按"细胞/无细胞"二分来建**。
   在噬菌体输出上训练而不显式建模这一先验的模型，会把"可制造性"学成"结合能力"；
   但把同一套校正直接套到 SICLOPPS 数据上，则是引入一个该平台并不存在的偏倚。

## 6. 与选择模拟的集成

`SimulationParameters.biosynthesis_platform` 置为任一平台键后，
`simulate_mrna_display` 用逐序列的机理展示概率替换共享标量 `fusion_probability`：

```python
from litrapid.mrna_display import SimulationParameters, simulate_mrna_display

result = simulate_mrna_display(
    candidates,
    SimulationParameters(rounds=6, biosynthesis_platform="mrna_rapid"),
)
```

缺省值为 `None`，保持原有总体平均行为不变（既有 15 项测试全部通过）。
也可只取概率表自行注入：

```python
from litrapid.biosynthesis import display_probability_table
table = display_probability_table([c["peptide_sequence"] for c in candidates], "phage_m13")
```

## 7. 命令行

```bash
PYTHONPATH=src python -m litrapid.biosynthesis compare --length 12
PYTHONPATH=src python -m litrapid.biosynthesis funnel  --platform phage_m13 --length 12
PYTHONPATH=src python -m litrapid.biosynthesis profile --platform mrna_rapid --sequence YSWDGFTLC
```

`profile` 对单条序列输出每一步的存活概率、累积概率、**限制步**及其机理说明。
限制步是本模块最可操作的输出：它指名该改哪一个实验条件，而一个聚合评分做不到这一点。

## 8. 边界与校准路径

本模块是**有机理依据的参数化，不是拟合模型**。每个函数形式都对应一个有文献记载的机理
（大环化 SN2 动力学、阳性在内规则、内含肽 +1 位亲核要求、OmpT 双碱性特异性），
但常数是为复现已报道的平台级文库规模与产率而取的数量级值。

- **可用**：跨平台比较、跨序列排序、限制步识别、文库设计（环尺寸、固定位点、密码子方案）决策。
- **不可用**：把任何一步的数值当作该步骤的实测产率引用。

校准路径：对单一平台取得分步实测数据（定量转录/连接产率、融合效率、LC-MS 成环转化率、
转化菌落计数、分选通量）后，逐步替换对应常数；序列相关项则应以同一文库的
**轮次解析 NGS**（第 0 轮 vs 第 1 轮，无靶点对照）重新拟合 ——
无靶点对照的第 0→1 轮变化，正是本模块所建模的生物合成先验的直接测量。
