# LitRaPID：文献与专利驱动的虚拟宏环肽发现平台

## 1. 定位与边界

LitRaPID 不模拟真实淘洗，而是复现 RaPID 的三个计算思想：扩展非天然宏环肽化学空间、对靶标进行条件化排序、随新证据迭代候选。它适合假设生成、情报分析、候选优先级和专利预警；没有实验时不能证明结合、选择性、通透性或药效。

公开证据表明这一设计具有数据基础：mRNA display 可处理超过 `10^12` 级宏环肽库，公开案例披露了文库、轮次和最终序列；已有可下载的 RaPID 库规模数据集；线性、单环和双环文库也已有直接比较研究。

参考入口：

- SARS-CoV-2 RBD 宏环肽 mRNA display 案例：<https://pmc.ncbi.nlm.nih.gov/articles/PMC8189037/>
- RaPID 文库规模公开数据集：<https://acs.figshare.com/articles/dataset/Diversity_Scale_of_Library_Matters_Impact_of_mRNA_Library_Diversity_Scales_on_the_Discovery_of_Macrocyclic_Peptides_Targeting_a_Protein_by_the_RaPID_System/28561933>
- 线性、单环、双环文库比较：<https://pmc.ncbi.nlm.nih.gov/articles/PMC7284801/>
- ChEMBL 官方 API：<https://www.ebi.ac.uk/chembl/api/data/docs>
- RAPID display/linker 相关专利：<https://patents.google.com/patent/US11970694B2/en>
- 宏环肽与筛选相关专利：<https://patents.google.com/patent/US20160209421A1/en>

## 2. 总体架构

```text
论文 / 补充材料 / 数据集 / 专利全文 / ChEMBL
                    ↓
       来源登记、许可记录、下载与版本固化
                    ↓
  文本/表格/图注/序列表抽取 → 人工复核队列
                    ↓
  宏环肽知识图谱 + 测定证据库 + 专利特征库
                    ↓
 Target Pack → 虚拟库生成 → 多目标预测与过滤
                    ↓
 多样性选样 + 不确定性 + IP预警 + 可解释候选卡
```

## 3. 六个核心模块

### 3.1 Evidence Harvester

输入 DOI、PMID、专利公开号、数据集 URL 或靶标名称。抽取肽序列、非天然残基、立体化学、环化键、靶标构建体、活性、测定方法、文库长度、轮次、反选和专利权利要求特征。

每个事实必须保存来源页码、表号或权利要求号。LLM 抽取只生成待审核记录，不能直接进入金标准训练集；图片/OCR 序列必须人工复核。

### 3.2 Peptide Normalizer

采用三层表示：原文表示用于审计；HELM 或等价单体—连接图用于规范化；残基 token、分子图、理化描述符和可选构象用于建模。不能把 D/L、N-甲基化或不同环化拓扑折叠成同一结构。

### 3.3 Target Intelligence

为每个目标生成 Target Evidence Pack：UniProt 序列、结构域、同源蛋白、物种差异、PDB/预测结构、潜在界面、已知肽/小分子/抗体表位、突变证据和期望机制。迁移学习同时参考全序列、结构域、局部口袋和界面，不能只按靶标名称迁移。

### 3.4 Virtual Library Designer

生成器接受明确约束：长度、允许单体、环化拓扑、净电荷、疏水性、复杂度和 IP 规则。候选按比例来自：已知家族改造、相似靶标迁移、motif 重组、生成模型新颖候选，以及高不确定但处于支持化学空间的探索候选。

近期针对 40 个公开数据集的分析显示，随机区长度与发现高效结合物的概率有关。这类跨项目统计适合作为生成先验，不应作为硬规则：<https://doi.org/10.1039/d5cc06167a>。

### 3.5 Multi-objective Ranker

建议综合评分：

\[
S=0.30A+0.15T+0.15D+0.10P+0.10N+0.10E-0.10R
\]

- `A`：靶标条件化结合/亲和概率；
- `T`：相对同源蛋白的选择性；
- `D`：溶解性、聚集、稳定性及通透性等可开发性；
- `P`：结构或口袋相容性；
- `N`：相对公开结构的新颖性；
- `E`：证据适用域，即目标和候选距训练数据的远近；
- `R`：IP 邻近、测定冲突与模型不确定性风险。

权重按项目配置。输出必须包含分数、置信区间、适用域和最近证据，禁止只给单一排名。

模型栈采用：规则硬过滤；肽 HELM/图编码器；蛋白序列与局部结构编码器；肽—靶标交互模型；活性、选择性和可开发性多任务头；梯度提升模型作为小数据可解释基线；最后进行集成与保序校准。

### 3.6 Patent Landscape & Design-around Assistant

专利模块分别处理：平台实施风险（linker、翻译偶联、重编程、筛选流程）、序列/结构风险（具体序列、通式、Markush、用途权利要求）以及与专利实施例的情报相似性。

系统只能输出“待律师复核的预警”，不能自动给 FTO 结论。法律状态必须带司法辖区和查询日期，并处理同族、继续申请、分案和失效差异。

## 4. 数据质量

| 等级 | 可接受证据 |
|---|---|
| A | 明确结构、靶标构建体、定量活性和正交验证 |
| B | 明确结构与单一可靠定量测定 |
| C | 只有富集、终轮序列或半定量活性 |
| D | 摘要、OCR、未核实专利实施例或推断 |

训练默认使用 A/B；C 用于弱监督；D 只用于检索和人工判断。同一化合物的不同测定保留独立记录，再经证据模型聚合。

## 5. 防止模型虚高

- 按论文和专利族分组切分，禁止同一来源类似物跨训练/测试集。
- 按序列簇、骨架簇和靶标家族做外推测试。
- 专利先公开、论文后发表的重复数据建立同源关系，不能重复计权。
- 用负结果、低活性结果和测定冲突训练不确定性，不能只收集成功案例。
- 新靶标若远离训练域，系统应降级为基于相似性和结构规则的保守排序。

## 6. 用户工作流

1. 输入靶标、物种、结构域、期望机制和允许的肽化学空间。
2. 生成 Target Evidence Pack 与数据缺口报告。
3. 选择保守优化、相似靶标迁移或新颖探索模式。
4. 生成虚拟库，执行化学合法性、预测、结构和 IP 过滤。
5. 以 Pareto front 或最大边际相关性选择多样候选，不直接取 Top-N。
6. 生成候选卡：结构、预测、置信度、最近邻、相反证据、来源和 IP 预警。
7. 新论文或专利公开后触发重评分，形成虚拟“下一轮选择”。

## 7. MVP 路线

### V0：证据库（4–6 周）

- 选择 5–10 个公开数据较丰富的宏环肽靶标；
- 人工复核 500–2,000 条结构—活性记录；
- 完成 HELM 标准化、证据分级、专利同族表；
- 提供检索、相似性和规则评分。

### V1：目标条件化排名（6–10 周）

- 建立序列/结构基线和严格簇外验证；
- 输出适用域和校准不确定性；
- 加入同源蛋白选择性和多样性选样。

### V2：生成与 IP 预警（8–12 周）

- 建立受约束的宏环肽生成器；
- 建立权利要求特征检索与结构邻近预警；
- 文献更新触发再训练，并解释排名变化。

## 8. 验收指标

- 序列簇外、骨架簇外和靶标家族外的 Top-k recall 与 enrichment factor；
- 活性误差、排序相关性和置信区间覆盖率；
- 新颖候选比例与化学合法率；
- 抽取字段精确率和人工复核通过率；
- 候选证据可追溯率；
- 专利预警召回率，由专利专业人员抽样复核。

随机拆分后的高 AUC 不能作为核心验收标准。

## 9. 最终产品形态

产品首页由四个工作台组成：Target Evidence、Virtual Library、Candidate Ranking、Patent Alerts。每个候选均可下钻到结构、模型适用域、相似序列、原始文献段落、专利权利要求和版本记录。

平台可复制的是 RaPID 的“海量空间探索、选择性排序和迭代优化思想”，不能复制真实展示筛选提供的靶标特异实验信号。正确的产品承诺是：把数百万虚拟候选压缩为少量、证据充分、结构多样、风险透明的优先候选。
